How a recommendation gets made

Four steps, every one inspectable — nothing here is a single opaque call to a language model.

  1. 01

    Fill the state

    Free text or JSON is parsed into a structured land state. If critical fields — soil carbon, rainfall, land use — are missing, the system asks rather than guesses, and remembers what you've already told it across turns.

  2. 02

    Retrieve

    The state is turned into a query and matched against the knowledge base and indexed reference reports using TF-IDF vector similarity — a real, inspectable retrieval step, not prompt text.

  3. 03

    Match conditions

    Each candidate intervention carries explicit applicability conditions. Retrieval score and condition match are combined into a single relevance score, so you can see exactly why something surfaced.

  4. 04

    Cross-link metrics

    The metrics touched by the top recommendations are checked against a table of known cross-variable relationships — soil carbon and species richness, rainfall and survival — so the answer connects variables instead of treating them in isolation.
